# SPAN Games

Projeto acadêmico de uma loja virtual demonstrativa de produtos gamer, desenvolvido para a disciplina Projeto de Desenvolvimento em Front-End do curso de Análise e Desenvolvimento de Sistemas da UNISUAM.

## Sobre o projeto

O SPAN Games reúne produtos para computadores e jogos em um catálogo online. O projeto foi criado como uma aplicação de front-end, com dados simulados no navegador por meio do `localStorage`. Ele não realiza pagamentos reais.

## Funcionalidades

- Catálogo de produtos, categorias e ofertas
- Pesquisa e filtro de produtos
- Cadastro, edição e exclusão de produtos
- Cadastro e login de usuários
- Perfil, feedback e histórico de pedidos
- Carrinho e fluxo demonstrativo de compra
- Alternância entre tema claro e escuro e ajuste do tamanho da fonte

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- `localStorage` para simular o armazenamento de dados no navegador

## Como visualizar

Acesse o site publicado: [SPAN Games](https://gabicdev.github.io/SPANGAMES/)

Para executar localmente, abra a pasta do projeto no Visual Studio Code e inicie o `index.html` com a extensão Live Server.
